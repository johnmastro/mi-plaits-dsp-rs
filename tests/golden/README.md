# Golden-test data

`manifest.toml` contains exact audio fingerprints for the canonical
`aarch64-apple-darwin` test environment. It is generated by the harness in
`tests/golden.rs`; do not edit fingerprints by hand.

Run `cargo test --test golden` to check the manifest. Set `GOLDEN=record` to
replace it intentionally, or `GOLDEN=wav` to check it and write stereo
listening files beneath `out/golden/`.
